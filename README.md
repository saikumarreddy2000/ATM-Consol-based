# 🏧 ATM Management System Using Python

## 📌 Project Description

This project is a **Console-Based ATM Management System** developed using Python. The application performs essential ATM operations such as account creation, PIN generation, balance inquiry, cash deposit, cash withdrawal, and mini statement generation.

The project is built using only **control statements**, **conditional statements**, **loops**, **functions**, and **dictionary data types** to manage user information and transaction details.

This project demonstrates a strong understanding of Python fundamentals and problem-solving skills without using databases or external libraries.

## 📋 Available Operations

### 1. Account Creation
Users can create a new account by providing basic details.

### 2. PIN Generation
Each user can generate a secure PIN for authentication.

### 3. Deposit Money
Users can deposit money into their account.

### 4. Withdraw Money
Users can withdraw money if sufficient balance is available.

### 5. Balance Inquiry
Users can check their current account balance.

### 6. Mini Statement
Users can view recent transaction details and current balance.
